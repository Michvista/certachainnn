## The Problem
Approximately **30% of CVs in Nigeria contain falsified credentials.** Manual verification processes take weeks, cost money, and are prone to human error. Legitimate graduates struggle to prove their advantage, while employers waste resources on unreliable background checks.
## The Solution
CertaChain is an integrated backend-to-blockchain system that makes certificate fraud structurally impossible through decentralized storage and on-chain anchoring.
### 🏛️ Layer 1 — Secure Issuance
Institutions upload certificates (PDFs/Images) through our dashboard. The backend uses **Multer** and **Pinata (IPFS)** to create a tamper-proof digital fingerprint (CID) of the document.
### 🎓 Layer 2 — On-Chain Data Anchoring
Every issued certificate is linked to a **Solana Program** on the Devnet. By storing the IPFS metadata URI and linking it to the student's wallet and the Solana Program ID, we create a "source of truth" that no central authority can alter.
### 🤖 Layer 3 — Gemini AI Skill Verifier
Employers don't just verify a name; they understand competence. Powered by **Google Gemini API**, our verifier parses multiple verified credentials to generate:
 * **Verified Skill Extraction:** Automated skill list from on-chain data.
 * **Credential Score:** A 100-point score based on verified achievements.
 * **Hiring Recommendations:** Strategic insights generated by AI analysis.
## Technical Architecture
The CertaChain backend is built as a robust Node.js bridge between decentralized protocols and the frontend.
### Core Tech Stack
| Component | Technology | Purpose |
|---|---|---|
| **Backend** | Node.js / Express | Central API & Logic Hub |
| **Blockchain** | Solana (Devnet) | On-chain verification source |
| **AI Engine** | Gemini 2.0 Flash | Skill analysis & report generation |
| **Storage** | IPFS via Pinata | Decentralized file & metadata hosting |
| **Database** | Prisma + PostgreSQL | High-speed cache for student records |
| **Email** | Nodemailer | Custodial wallet claim delivery |
| **Validation** | Zod | Strict schema enforcement for data integrity |
### Key Backend Implementation Details
 * **Multer File Processing:** Handles certificate uploads directly to memory before streaming to IPFS, ensuring no sensitive files remain on the server.
 * **IPFS Metadata Wrapping:** Automatically generates standardized JSON metadata for every certificate, including course details, grades, and issue dates.
 * **Custodial Wallet System:** Automatically generates Solana Keypairs for students without wallets and sends secure claim links via email.
## API Endpoints
### 1. Issue Certificate
POST /api/certificates/issue
 * **Purpose:** Handles Multer file upload, pins to IPFS, and saves the on-chain reference to the database.
 * **Validation:** Zod-enforced schema for student details.
### 2. AI Skill Report
POST /api/ai/skill-report
 * **Purpose:** Sends a batch of verified credentials to the **Gemini API**.
 * **Output:** JSON object containing summary, skillsVerified, and overallScore.
### 3. Custodial Claim
POST /api/users/claim
 * **Purpose:** Generates a new Solana wallet and sends a **Nodemailer** email to the student with a claim token.
## Getting Started (Backend)
### Prerequisites
 * Node.js v18+
 * PostgreSQL database
 * Pinata API Keys
 * Gemini API Key
### Setup
 1. Clone the repo and cd backend.
 2. Install dependencies: npm install.
 3. Configure .env:
```env
PINATA_API_KEY=your_key
GEMINI_API_KEY=your_key
EMAIL_USER=your_gmail
EMAIL_PASS=your_app_password
DATABASE_URL=your_postgresql_url
SOLANA_PROGRAM_ID=DFT8JMHf3qkQw8yWqw3q9T9dTkJRAZVtAz8DZchUxJ2u

```
 4. Run migrations: npx prisma migrate dev.
 5. Start server: npm run dev.
